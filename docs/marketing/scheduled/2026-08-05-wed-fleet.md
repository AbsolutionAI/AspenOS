# Wed Aug 5 — Standardized work is the oldest agent protocol

## Draft post

```
Standardized work is the oldest agent protocol in manufacturing.

Every plant floor runs on it: a written procedure for every tool change, a checklist for every shift handoff, a sign-off for every deviation. The plant doesn't trust memory — memory drifts between Monday and Friday, between first shift and third.

We've started running our agent fleet the same way.

Each agent gets:
• a start gate (is this task worth the model call? who approved the budget?)
• a runtime check (still under limit? still on track?)
• a handoff note (what did this agent touch that the next agent or human needs?)

The plant isn't going to run our stack. The discipline pattern still crosses the gap.

If your fleet has no gates, checklists, or handoff artifacts, you're running on memory. Factories abandoned verbal-only handoffs for a reason.
```
