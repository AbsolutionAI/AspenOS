# Fri Aug 14 — Product spotlight: React Admin Dashboard ($49, hard CTA)

## Draft post

We spent this week talking about proving before shipping. Here's one we proved.

The React Admin Dashboard started as an internal scaffold — the thing we cloned every time we needed to spin up an admin panel for a new micro-agent UI. Auth, routing, dark mode, sidebar, data tables, API client, loading states. The same 12 files every time.

After the 5th clone we stopped calling it "scaffold" and started calling it a product. But we held it until:

- Every page template had been used in at least two real projects
- The auth flow had survived a production token refresh cycle
- The API error handling had caught real 4xx/5xx responses (not just mock data)
- The dark mode switch didn't flash white on first load (the hardest bug, and the one that proves you actually shipped it to real users)

It passed the first article. Now it ships.
