Operator note: How a scaffold becomes a product.

We build admin UIs for micro-agent control panels — dashboards to monitor fleet state, review eval runs, toggle agent budgets. After the fourth time cloning the same auth router, sidebar layout, and data table component, we extracted a starter.

It sat in a private repo for three months before we called it shippable. The gate wasn't feature count — it was repetition threshold. Every component had to survive:
- Two different auth providers (JWT refresh cycles reveal every bad state handler)
- Three API client rewrites (real 4xx responses, not mock data)
- One dark mode flash bug that only surfaces on real device refresh, not hot reload
- Deployment to actual subpaths behind a reverse proxy

The template passed when we stopped finding bugs in the clone — only in the new project logic on top of it.
