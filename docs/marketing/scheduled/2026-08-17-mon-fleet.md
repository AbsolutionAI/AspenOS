# Mon Aug 17 — Fleet discipline: the agent you forgot about that's still billing you

## Draft post

If you run a multi-agent fleet and haven't checked your cost-per-agent: you're probably burning budget on agents that do nothing useful.

We had a reflection coach that was always-on. It ran every 4 hours. In theory it checked agent outputs for drift and flagged when a model started degrading. In practice, it produced 0 actionable flags in six weeks. The first time it ever said something interesting was when *we* asked it a direct question during debugging.

But for those six weeks, every 4 hours, it drafted a report, wrote it to disk, and billed its inference credits. $12/month for a heartbeat that nobody read.

The fix wasn't better prompting. It was a simple rule: **every agent must justify its next wake cycle in its last output.** If an agent writes no actionable signal for 7 consecutive runs, it gets auto-paused until a human or another agent re-requests it by name.

That rule caught three more agents in the first month: a summarizer that summarized only itself, a metrics aggregator that duplicated the dashboard, and a "status reporter" that nobody remembered adding.

Wake-on-demand isn't just cheaper — it's a signal filter. If an agent has to earn its next cycle, you learn very fast which ones actually pull their weight.
