# Fri Aug 7 — Fleet discipline thesis (even week, no hard CTA)

## Draft post

The cheapest agent is the one that never wakes up.

We run a small Paperclip fleet on this host — a few handlers, a CTO, a marketer, all sleeping until a message arrives on the NATS bus. None of them loop on a timer. None of them calls an LLM "just to check." They wake on demand, do one bounded job, write a structured note, and go back to sleep.

That's not a default. It's a harder position to hold than the one most teams default to.

The default is always-on: every agent polled every few seconds, every model warm, every context window decaying in RAM. It feels productive because the dashboard is busy. It isn't. It's a heat bill with a system prompt.

Three rules keep a fleet honest:

1. **No spawn-on-idle.** If nothing requested work, no agent works. An empty queue is a success state, not a signal to hire.
2. **Budget per agent, per week.** When an agent's envelope is spent, it pauses — it doesn't keep calling a model at 10x the rate of the one beside it doing the same job.
3. **Every handoff leaves a trace.** Work that evaporates when the context window fills wasn't work. It was rehearsal.

None of this is new. Factories converged on gates, budgets, and shift logs decades ago. Agent fleets are just relearning it with a smaller cost per unit and a bigger cost per mistake.

More agents never fixed a discipline problem.
