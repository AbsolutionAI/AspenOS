# ASP-499: Fix fleet bus smoke test — aspen_edge module not found

## Status: Implemented

## Problem

`scripts/smoke-fleet-bus.py` was referenced in `third_party/pins.json` as the consumer of `aspen-edge-rrm` and `aspen-swarm-manager`, but the file never existed in the repository. The CI workflows cloned the sibling repos but had no smoke test to exercise them.

## Approach

1. Create `scripts/smoke-fleet-bus.py` — a standalone Python smoke test (86 lines, 18 checks) covering:
   - `aspen_edge` module import (FleetBus, OpsManager, EdgeRRM)
   - In-process publish/subscribe round-trip (CloudEvents envelope)
   - OpsManager node registration + heartbeat tracking
   - EdgeRRM lifecycle (start, register, heartbeat)
   - Estop/clear dual-authorization cycle with micro-agent mediation
   - `aspen_swarm` module import + mission lifecycle (submit, auto-start, complete)

2. Edit `scripts/smoke-test.sh` line 80 to add a fleet-bus check with `PYTHONPATH=../aspen-edge-rrm:../aspen-swarm-manager`
