# ASP-518: Nightly Packaging & Deployment Check — Hardening

## Problem

The nightly check (ASP-512) landed but has not been validated end-to-end. Running `check-nightly.sh` locally reveals failures:

1. **Shell syntax bug in `scripts/restore.sh`** — line 157 uses `[[ ! - "$archive" = /* ]]` (invalid), would fail on any restore operation at runtime.
2. **Nightly CI would fail on fleet-bus smoke test** — the smoke suite includes a fleet-bus check that requires sibling repos (`aspen-edge-rrm`, `aspen-swarm-manager`), but the nightly workflow doesn't clone them.
3. **Ops doc not updated** — `docs/ops/NIGHTLY_PACKAGING_DEPLOY_CHECK.md` references stale check count and doesn't describe CI infrastructure dependencies.

## Scope

- Fix `restore.sh` shell syntax bug
- Add sibling repo checkout to `.github/workflows/nightly.yml`
- Update `docs/ops/NIGHTLY_PACKAGING_DEPLOY_CHECK.md` to reflect current checks and CI infra
- Write compound learning at `docs/solutions/asp-518-nightly-check-fixes.md`
