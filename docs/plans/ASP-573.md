# ASP-573: H-007 — Add integration test for estop dual-human clear

## Summary

Close H-007 (CVSS 9.0, P0#1 in `docs/SECURITY_THREAT_MODEL_v2.2.md`) by adding a
dedicated integration test in the Aspen OS repo (repo of record) that confirms a
single `aspen.safety.authorize_clear` alone never unlatches the estop. The estop
dual-human clear gate already exists in the sibling `aspen-edge-rrm` repo (merged
to master as `f4f2c8d` with `TestEstopDualHumanClear`), but the Aspen OS side:

- still pins the **pre-gate** `aspen-edge-rrm` commit in `third_party/pins.json`,
  so CI and nightly clone and exercise the vulnerable RRM; and
- has no dedicated negative-case integration test asserting `clear` alone or
  single `authorize_clear` never unlatches.

## Changes

### 1. `scripts/smoke-fleet-bus.py` — dedicated H-007 negative-case integration test

After the existing "estop blocks proposal" check, replace the unconditional clear
block with a full H-007 scenario:

| Step | Publish | Assertion |
|------|---------|-----------|
| latch | `aspen.safety.estop` | `rrm.estop is True` |
| 1 | bare `aspen.safety.clear` | estop stays True; audit has `clear_refused_insufficient_auths` |
| 2 | `authorize_clear` (single human) + `clear` | estop stays True; refusal audited |
| 3 | second distinct `authorize_clear` + `clear` | estop becomes False; `clear` audited |

This is the "dedicated integration test" — it runs in-process against the pinned
`aspen-edge-rrm` RRM through the real `FleetBus` subjects.

### 2. `third_party/pins.json` — bump `aspen-edge-rrm` to gated master

Move the pin from `aa3f84d` (pre-gate) to the current master head containing the
gate, so CI/nightly clone and exercise the gated RRM.

Current master head: `6a8f1ae` (superset of `f4f2c8d` gate + `6a8f1ae` sentinel
consumer).

### 3. `scripts/smoke-test.sh` — surface the H-007 check

Add an explicit named check line for visibility:
`fleet-bus H-007 dual-human clear gate` running `scripts/smoke-fleet-bus.py`.
(The suite already fails if any `check()` inside the script fails.)
