# ASP-813: Nightly Packaging & Deployment Check

## Problem
Run the scheduled nightly packaging and deployment verification against the current `origin/master` to detect regressions in build toolchain, Debian packaging, systemd units, shell syntax, key files, Python test suite, NATS configs, security gates, ISO structure, and dashboard assets.

## Success Criteria
1. `scripts/check-nightly.sh` runs to completion
2. Results recorded in `docs/ops/NIGHTLY_LATEST.md` with timestamp, git SHA, verdict, pass/fail counts, and any deviations
3. Commit on `ASP-813-nightly-packaging-deployment-check` branch
4. QA gate child created for Aider, this issue set blocked pending QA
