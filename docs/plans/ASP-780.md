# ASP-780: Sentinel tool-anomaly consumer hardening (PR #76 follow-ups)

**Issue:** [ASP-780](/ASP/issues/ASP-780)
**Status:** Planned — 2026-11-24
**Base:** `origin/master`

## 1. Problem

Post-hoc review of PR #76 (ASP-687 tool-anomaly consumer) found 6 hardening items
required before the consumer can run as a service:

| # | Issue | Risk |
|---|-------|------|
| 1 | NATS connect has no TLS/creds — only as secure as the URL | Credential exposure, MitM on audit stream |
| 2 | `add_stream` on `ASPEN_SENTINEL` — first-writer-wins stream settings | Silent misconfiguration; operator-defined stream params are overwritten |
| 3 | Per-finding `fsync` inside the message handler blocks the event loop | NATS slow-consumer drop under load |
| 4 | Unbounded actor map in `ToolAnomalyDetector._history` | Memory leak under sustained unique-actor traffic |
| 5 | Random `finding_id` defeats `Nats-Msg-Id` dedupe | Duplicate findings and pages on replay |
| 6 | Minor: OSError skips publish silently, errors logged at debug, `tail()` reads whole file, `_env_int` is unused | Observability gaps, wasted I/O |

## 2. Changes

### Item 1 — NATS connect with TLS/creds

Reuse `agents/nats_connect.py` helpers (`build_nats_url`, `connect_kwargs`, `safe_url`)
in `ToolAnomalyConsumer._connect()` instead of calling `nats.connect(url)` directly.
Add `ASPEN_NATS_CREDS` env for JWT `.creds` file support (above the shared helper).
Log warnings when connecting to a remote broker without auth+TLS (H-024).

### Item 2 — Stream existence check

Replace `_ensure_stream()` `add_stream` call with a `stream_info()` existence check
guarded by a `create_stream` flag (False in production, True for dev/test only).
If the stream does not exist, log ERROR and run journal-only — stream settings
belong to the operator / `sentinel.audit` publisher.

### Item 3 — Async fsync

Move `_append_journal()` file writes to a `run_in_executor` (thread pool) so fsync
never blocks the event loop. Uses a `concurrent.futures.ThreadPoolExecutor` owned by
the consumer lifecycle.

### Item 4 — Bounded actor map

Add `max_actors` and `idle_timeout_s` params to `ToolAnomalyDetector`.
Evict actors with no events within the idle window on each `feed()` call.
Enforce a hard cap (`max_actors`, default 1024) with LRU eviction.

### Item 5 — Deterministic finding_id

Replace `uuid.uuid4().hex` in `_envelope()` with a hash of (rule, actor, sorted
source event ids). Use `SHA-256` truncated to 32 hex chars.

### Item 6 — Minor fixes

- OSError on journal write: log warning, do not skip publish
- Log anomalies at warning, not debug
- `tail()` uses reverse-line reads instead of loading the whole file
- Remove unused `_env_int` function
