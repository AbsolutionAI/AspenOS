# ASP-780: Sentinel tool-anomaly consumer hardening (PR #76 follow-ups)

**Issue:** [ASP-780](/ASP/issues/ASP-780)
**Parent:** ASP-687 sentinel tool-anomaly detector
**Status:** Planned — 2026-11-26
**Base:** `origin/master`

## 1. Problem

ASP-687 / PR #76 (merge `5dea57b`) wired the tool-anomaly detector to the live audit stream. It was merged without review. Post-hoc review found 6 issues that must be fixed before the consumer can run as a service.

## 2. Items

| # | Issue | File | Fix |
|---|-------|------|-----|
| 1 | NATS connect has no TLS/creds (L197-205) | `src/python/sentinel/tool_anomaly_consumer.py` | Reuse connection setup from `sentinel/audit.py` which has TLS + creds options (nats_options, tls_first, connect_timeout) |
| 2 | `add_stream` on `ASPEN_SENTINEL` (L247-253) | `src/python/sentinel/tool_anomaly_consumer.py` | Replace bare except with stream_info existence check; fail loudly if missing or misconfigured |
| 3 | Per-finding fsync inside message handler (L323-329) | `src/python/sentinel/tool_anomaly_consumer.py` | Move fsync to executor or batch — fsync blocks the event loop |
| 4 | Unbounded actor map (`tool_anomaly.py` L227-243) | `src/python/sentinel/tool_anomaly.py` | Add idle eviction and/or hard cap on `_history` dict |
| 5 | Random `finding_id` (L317) | `src/python/sentinel/tool_anomaly_consumer.py` | Make deterministic: hash of (rule, actor, source event id) |
| 6 | OSError on journal write skips publish | `src/python/sentinel/tool_anomaly_consumer.py` | Ensure publish still happens if journal write fails |
