### `fix/test-collection-optional-deps` — superseded, delete

Both touched files already carry the equivalent guard on master:

- `tests/test_server.py` — master has `pytest.importorskip("aiohttp", ...)`. Branch differs only in
  the skip reason string and a `# noqa: E402`.
- `tests/test_memory_mcp.py` — master uses a `ModuleNotFoundError` guard that skips on
  `mcp.server` and **re-raises** anything else; the branch replaced it with a bare
  `pytest.importorskip("mcp.server", ...)`. Master's is strictly stronger: `aspen_memory_mcp` is
  in-repo (`mcp/aspen-memory-mcp/src`), so a genuine import failure inside it must fail the suite
  rather than skip. The branch version would have hidden it. Delete the branch; keep master's guard.

### `fix/ci-assertion-hardening` — **not** superseded. Do not delete.

The ticket asserts `scripts/smoke-test.sh:37` already has the PATH + `command -v` guard and
`smoke-test.sh:58` / `ci.yml:121` already use `--help >/dev/null`. That is true of
`smoke-test.sh` — but the branch's unique content is in `ci.yml`, and master does **not** have it:

```
$ git show origin/master:.github/workflows/ci.yml | grep -n 'set -euo\|command -v nats-server'
(no matches)
```

Branch `236f7b1` adds, on top of a much older base:

- `set -euo pipefail` in the `smoke` job's install step
- a `command -v nats-server` guard around the download + `sudo cp`
- `tests/test_ci_assertions.py::test_ci_nats_install_is_guarded` asserting both

None of that is on master. Cherry-picking `236f7b1` is also not safe: its base predates the
`security-devonly-isolation`, `verify-package-signature`, and `security-model-digests` CI jobs and
~12 later `smoke-test.sh` checks, so it removes them. The branch is stale, not redundant.

Honest value assessment: the `command -v` guard is idempotency (skip a re-download), not a
correctness fix — GitHub Actions runs steps with `bash -e`, so a failed `curl | tar` already fails
the step. `set -euo pipefail` is the part with real teeth. Neither is urgent, and changing CI is
outside "no code lands from any of these". So: **leave the branch in place**, and file the port as
its own scoped task instead of deleting the evidence.
