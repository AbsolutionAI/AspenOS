# ASP-539: Replace hardcoded NATS URL in scheduler.py with env/config

## Problem

`scheduler.py` (both in `agents/` and `src/python/lib/`) hardcodes the NATS server URL as `"nats://[IP_ADDRESS]:4222"` directly in the `nats_connect()` call, with no env-var indirection.

## Solution

Replace the hardcoded string with `os.getenv("NATS_URL", "nats://[IP_ADDRESS]:4222")`, following the same pattern used by 30+ other modules in the codebase.

## Files to modify

1. `agents/scheduler.py` — add `import os`, replace URL
2. `src/python/lib/scheduler.py` — add `import os`, replace URL

## Testing

No scheduler-specific tests exist. The change is a one-line mechanical substitution matching an established codebase convention. Verify by syntax check.
