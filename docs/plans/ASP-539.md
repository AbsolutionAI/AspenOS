# ASP-539: Replace hardcoded NATS URL in scheduler.py with env/config

## Problem

`scheduler.py` (both in `agents/` and `src/python/lib/`) hardcodes the NATS server URL as `"nats://127.0.0.1:4222"` directly in the `nats_connect()` call, with no env-var indirection.

## Solution

Replace the hardcoded string with `os.getenv("NATS_URL", "nats://127.0.0.1:4222")`, following the same pattern used by 30+ other modules in the codebase.

## Files to modify

1. `agents/nats_connect.py` — default URL `"nats://127.0.0.1:4222"` → `"nats://127.0.0.1:4222"` (the source of truth for all `nats_connect` callers)
2. `agents/scheduler.py` — default URL `"nats://127.0.0.1:4222"` → `"nats://127.0.0.1:4222"` (via `nats_connect`)
3. `src/python/lib/scheduler.py` — default URL `"nats://127.0.0.1:4222"` → `"nats://127.0.0.1:4222"` (env var + loopback)
4. `dist/pkgroot/opt/starship/lib/starship/agents/nats_connect.py` — same fix
5. `dist/pkgroot/opt/starship/lib/starship/agents/scheduler.py` — same fix
